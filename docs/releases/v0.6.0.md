# Milo v0.6.0（正式版）

## 本次重点

Milo 完善了 npm 安装、升级和卸载流程，并支持简体中文和英文界面。默认使用简体中文，不受支持的语言回退到英文。

## 新增

- 可通过 `social` 配置 GitHub、邮箱、订阅、网站等 12 个内置入口及自定义平台，通过 `menu` 自定义导航。

## 优化

- npm 包附双语文字文档，并加入打包、安装和页面生成的自动化检查。
- 提供双语快速入门、完整使用指南及配置参考。
- 完善可直接复制的统一配置模板，补齐默认值与示例。
- 手机与单列平板导航菜单居中，作者链接逐行居中，英文统计标签保持完整单行。
- 搜索能匹配正文中的 HTML 实体和规整后的空白，并正确处理快速连续输入。

## 修复

- 修复开启分页的空站点缺少首页的问题。
- 页脚技术署名统一使用英文，并链接到当前主题仓库。
- 正确使用站点 Atom／RSS 生成器的订阅地址。
- 双行导航下，吸附侧栏和目录会随导航高度调整位置。

## 使用提醒

- Git 和 npm 安装均使用 `theme: milo`。站点根目录的 `_config.milo.yml` 可以继续使用。
- 从 npm 官方注册表安装此版本，运行 `npm install hexo-theme-milo@0.6.0`。
- 省略站点语言时使用简体中文，指定的语言均不受支持时回退到英文。

## 兼容性与验证

- Windows 上使用 Node.js 22、24、26 和 Hexo 8.1.2 运行自动化回归，使用 Node.js 26 验证 npm tarball 升级，覆盖根路径与子路径。
- Safari、macOS 浏览器、Android/iOS 真机、屏幕阅读器及 Disqus 真实论坛联调仍待验收。

## English

Milo 0.6.0 adds Simplified Chinese and English, configurable navigation, and 12 built-in author link types alongside custom platforms. When the site has no language setting, Milo uses Simplified Chinese. Unsupported selections fall back to English.

- Centered navigation on phones and single-column tablets, centered author links, and single-line English statistics.
- Bilingual quickstarts and guides, matching Chinese- and English-commented configuration templates, and a ready-to-copy Demo configuration.
- Search matching and stale-result fixes, an empty-site homepage, accurate Atom and RSS discovery, and English technical credits with dynamic version numbers.
- Upgrade by retaining the site-root `_config.milo.yml` and setting `theme: milo`. Git and source archives remain supported. To install this release from the npm registry, run `npm install hexo-theme-milo@0.6.0`.
- Tested with Hexo 8.1.2 and Node.js 22, 24, and 26 on Windows, including root and subdirectory builds. Safari, macOS browsers, real Android/iOS devices, screen readers, and a live Disqus forum remain unverified.
