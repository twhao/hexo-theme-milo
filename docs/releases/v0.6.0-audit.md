# Milo v0.6.0 发行审计

## 代码及资料

审计范围为 v0.5.1 至 v0.6.0。配置延续 Hexo 的站点配置、独立主题配置和文章 Front Matter。升级回归逐字节比较站点配置。20 个公开主题字段在全新站点逐项验证，双语模板用 Hexo 解析后比较有效值和键顺序。

| 范围 | 结论 |
| --- | --- |
| HTML、社交和导航 | EJS 转义标签和属性。菜单与社交入口接受站内路径及 HTTP(S)，邮箱额外允许 mailto。内置 SVG 图标来自固定路径数据。 |
| 站点作者的内容 | Hexo 文章可包含 HTML，页脚自定义字段保留可信 HTML，主题颜色来自站点维护者配置。应将文章、模板和配置的写入权限授予可信作者。 |
| 国际化和搜索 | 站点未指定语言时使用简体中文，无法匹配支持的语言时使用英文。浏览器使用文本节点高亮，过期异步查询由序号丢弃，失效索引可重试。 |
| 评论与隐私 | 配置有效 Disqus shortname 后才显示按钮，点击才向第三方加载。使用文章规范 URL 标识讨论串，支持失败重试和单篇禁用。 |
| 图片与灯箱 | 图像尺寸读取限制在本地，远程图片不由构建器抓取。WebP 缺失时继续用原图，灯箱保留原图及已有图片链接。 |
| 订阅 | 内置 Atom 对文本做 XML 转义。站点 Atom／RSS 生成器优先，子路径的规范地址、订阅发现和作者入口由构建回归验证。 |
| UI 与资源 | 保留既定视觉，手机和单列平板菜单居中，英文统计保持单行，作者链接换行时逐行居中。实图随源码分发，npm 包仅包含双语文字文档、配置模板与运行资源。 |

## 依赖安全

官方注册表重新执行的主题生产依赖和完整依赖审计均为 0 告警。本地 Demo 锁文件的审计亦为 0。下表来自此前新站保留的旧依赖锁文件，npm 报告的是 6 个受影响包，部分包关联多个公告。这些包均不属于 Milo 的生产依赖。

| 受影响包 | 公告及严重程度 | 依赖链与实际影响 |
| --- | --- | --- |
| @tootallnate/once 2.0.0 | [CVE-2026-3449](https://github.com/advisories/GHSA-vpq2-c234-7xj6)，低 | 旧版 `hexo-renderer-marked → jsdom → http-proxy-agent → @tootallnate/once`。特定异步清理场景可影响本地渲染进程可用性。 |
| compression 1.7.4 | [CVE-2026-87776](https://github.com/advisories/GHSA-vc2v-76pw-4v95)，高 | `hexo-server → compression`。HTTP 压缩响应提前关闭时可能泄漏内存，长期运行且可从公网访问的开发服务可受拒绝服务影响。 |
| morgan 1.10.0 | [CVE-2026-5078](https://github.com/advisories/GHSA-4vj7-5mj6-jm8m)、[CVE-2026-15603](https://github.com/advisories/GHSA-jxfw-x594-9x9m)、[CVE-2026-87859](https://github.com/advisories/GHSA-9f6g-j8ch-79g4)，中 | `hexo-server → morgan`。开启 HTTP 日志并记录不可信请求字段时，日志完整性可能受影响。 |
| on-headers 1.0.2 | [CVE-2025-7339](https://github.com/advisories/GHSA-76c9-3jph-rj3q)，低 | `hexo-server → compression/morgan → on-headers`。响应头中间件处理特定调用形式时可能写入意外响应头。 |
| send 0.18.0 | [CVE-2024-43799](https://github.com/advisories/GHSA-m6fv-jmcg-4jfg)，低 | `hexo-server → serve-static → send`。文件服务的重定向响应可在特定条件下引发 XSS，涉及运行中的 HTTP 服务器。 |
| serve-static 1.15.0 | [GHSA-cm22-4g7w-348p](https://github.com/advisories/GHSA-cm22-4g7w-348p)，低 | `hexo-server → serve-static`。目录重定向响应可在特定条件下引发 XSS，涉及运行中的 HTTP 服务器。 |

Milo 发布包与静态构建产物不携带 Hexo 开发服务器。文档中的本地开发服务绑定回环地址，线上部署以静态文件为输入。保留旧锁文件的站点应检查并更新上游依赖，避免将 Hexo 开发服务器暴露到公网。

已在隔离新站安装 Hexo 8 适用的 `hexo-renderer-marked@7`，并通过 `npm update compression morgan serve-static` 更新现有范围内的开发服务器间接依赖。复查结果为 0 告警，未改动 Milo 依赖或采用强制升级。
