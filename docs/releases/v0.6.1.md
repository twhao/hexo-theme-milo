# Milo v0.6.1（正式版）

## 本次重点

修正 npm 软件包附带的双语安装文档，移除 v0.6.0 包内残留的候选版说明。

## 新增

本次无新增功能。

## 优化

中英文 README 和使用指南均优先推荐 `npm install hexo-theme-milo`。本地 tarball 安装说明放在使用指南的开发与离线安装小节。

## 修复

更新安装示例、版本信息和包内文档的截图链接。

## 使用提醒

在 Hexo 站点根目录运行 `npm install hexo-theme-milo`。已有 npm 安装可运行 `npm install hexo-theme-milo@latest` 更新。保留站点根目录的 `_config.milo.yml`。

## 兼容性与验证

沿用 v0.6.0 的运行环境、主题功能、界面、配置结构和默认行为。已在 Node.js 26.13.0 和 Hexo 8.1.2 下验证打包、安装、升级、构建及卸载。
